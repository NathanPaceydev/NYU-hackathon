The Solution

One entangled probe → QFI scales as N², not N

  • Generate a squeezed vacuum (LIGO runs 15 dB; commercial units exist)
  • Distribute through a beam-splitter network → N entangled modes
  • Each node imprints a contaminant phase φᵢ
  • Local homodyne readout (cheap, off-the-shelf)
  • Estimate regional sum q = Σ wᵢφᵢ → QFI ∝ N²
Scope: detect if the region is contaminated. Localization (which node) is a separate classical step — entanglement is not needed there.

What the code computes

  • Loads 8,889 real USGS wells; maps arsenic (µg/L) to phase φᵢ = s·cᵢ
  • Builds the full Gaussian covariance matrix for N modes
  • Computes QFI: F = 4(dd)ᵀV⁻¹(dd) + 2Tr[(V⁻¹dV/dθ)²]
  • Error = 1/√F in µg/L (homodyne saturates QCRB)
The Honest Limits

What this experiment does and does not claim

Coding / simulation limits

  • Ideal homodyne — no detector inefficiency modeled
  • Loss mixes with zero-temp vacuum, not thermal bath
  • No finite squeezing fidelity, no phase drift
  • N restricted to powers of two (2…64)

Data / physics limits

  • Phase ∝ contamination is assumed, not calibrated (s = 0.01 rad/µg/L)
  • No sensor chemistry or real readout modeled
  • Advantage is aggregate-only: "is the region contaminated," not which node
  • No quantum speedup claimed for sensor placement

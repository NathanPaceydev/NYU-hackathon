# References used for the jury revision

Local copies of the sources behind the new numbers. The open-access papers are arXiv preprints. Casacio's supplementary information and peer-review file are Nature ESM files. The Biacore sheet and EPA record are public web pages.

| File | Used for |
|---|---|
| `Zhuang2018_distributed_quantum_sensing_cv.pdf` (arXiv 1711.10459) | The sensing method: one squeezed beam shared across taps |
| `Guo2020_distributed_quantum_sensing_cv_network.pdf` (arXiv 1905.09408) | Experimental demonstration of the same method |
| `DemkowiczDobrzanski2012_elusive_heisenberg_limit.pdf` (arXiv 1201.3940) | With loss, the gain is a constant factor ≤ 1/√(1−η), not √N |
| `Dowran2018_quantum_enhanced_plasmonic_sensing.pdf` (arXiv 1802.00410) | Plasmonic shot-noise level 8.6e-10 RIU/√Hz; 9 dB → 4 dB squeezing, so η ≈ 0.69 |
| `Casacio2021_supplementary_information.pdf` | Total efficiency 0.44 (0.75 × 0.82 × 0.72) |
| `Casacio2021_peer_review_file.pdf` | 35 % SNR gain for cell imaging (power SNR, so 1.16× lower error) |
| `Biacore_T200_specifications_CEITEC.pdf` | Commercial SPR baseline noise < 0.03 RU RMS (3e-8 RIU), drift < 0.3 RU/min |
| `EPA_HERO_7429052_SPR_microcystin_biosensor.html` | Classical SPR microcystin-LR detection limit 73 ± 8 ng/L |

Not downloaded (paywalled): Casacio et al., Nature 594, 201 (2021), main text; Hale & Querry, Appl. Opt. 12, 555 (1973); Saunders et al., Appl. Opt. 55, 947 (2016).

## Scientific plots

All six plots in `Team_7_Ideation_Visual.pptx` use project simulation results, rebuilt as native editable charts with embedded workbooks. They show continuous monitoring, ideal scaling, regional loss, pilot error, detection probability, and thermal sensitivity. None of the result plots comes from a stock-image source. Captions identify the setup and interpretation; speaker notes contain limitations and primary references. Sources for the SDG targets are [UN Goal 6](https://sdgs.un.org/goals/goal6).
